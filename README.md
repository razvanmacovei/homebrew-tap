# homebrew-tap

Personal Homebrew tap for [razvanmacovei](https://github.com/razvanmacovei)'s tools.

## Usage

```
brew install razvanmacovei/tap/nightswatch
```

## Formulae

| Formula | Description |
| ------- | ----------- |
| [`nightswatch`](https://github.com/razvanmacovei/nightswatch) | Keep your Claude Code sessions moving overnight: auto-approve prompts, wait out usage limits, resume automatically (macOS + iTerm2) |
